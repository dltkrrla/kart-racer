# 🏁 카트 레이서 4P

폰 브라우저에서 바로 하는 3D 4인 카트 레이싱 웹게임 (three.js).

**플레이:** https://dltkrrla.github.io/kart-racer

- 방 만들기 → 방 코드(또는 🔗초대 링크)를 친구에게 보내기 → 친구는 코드 입력 후 참가
- 가속 자동 · ◀ ▶ 핸들 · 드리프트 누른 채 꺾다가 놓으면 부스터
- ? 상자 = 부스터 아이템, 슬립스트림, 뒤처질수록 약간 빨라지는 따라잡기 보정
- 혼자 연습 모드: 컴퓨터 3대와 레이스
- 연결: PeerJS(WebRTC) P2P, 방장 폰이 호스트
